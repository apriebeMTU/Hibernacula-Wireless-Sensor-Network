0   General Instructions 
0.1   Safety Warning
When assembling the temperature node, you will need to operate a soldering iron, a hot glue gun, and a high-speed handheld rotary tool. Before operating a tool, check your workspace to make sure it is safe. Always keep track of the hot or cutting end of the tool you are using. Use fume extractor when using soldering iron. Wear safety glasses when soldering or using rotary tools. Make sure to tie your hair back and avoid loose clothing or jewelry when operating the rotary tool. Secure the workpiece before operating the rotary tool. Follow the manufacturers’ safety instructions for all tools.
